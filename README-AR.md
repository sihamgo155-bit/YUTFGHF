# CIA CASA STREET RP — ELITE V2

واجهة تجنيد خيالية لمشروع ألعاب وRoleplay، بتصميم أسود وأحمر ومؤثرات خفيفة، وتدعم العربية والإنجليزية والإسبانية مع تخطيط متجاوب للهاتف والكمبيوتر.

## الملفات
- `index.html`: الصفحة العامة، قسم التعريف واستمارة التقديم فقط.
- `admin.html`: صفحة الإدارة المنفصلة.
- `styles.css` و`admin.css`: التنسيق والحركة والتجاوب.
- `app.js`: اللغات واستمارة التقديم التجريبية.
- `admin.js`: لوحة الإدارة التجريبية.

## تجربة الموقع
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح لمعاينة الموقع.
3. صفحة الإدارة منفصلة: `admin.html`.
4. رمز الدخول التجريبي: `1937`، ويظهر أثناء الكتابة على شكل نقاط.

## مهم قبل النشر
هذه النسخة تحفظ الطلبات والأعضاء في `localStorage` في نفس المتصفح والجهاز فقط. لا ترسل الطلبات إلى Discord ولا تجعلها مشتركة بين أجهزة مختلفة. كذلك رمز `1937` موجود في JavaScript ويمكن اكتشافه، لذلك لا تعتبره حماية فعلية. قبل استخدام بيانات حقيقية، اربط الموقع بخلفية آمنة مثل Supabase، مع مصادقة وصلاحيات من جهة الخادم، ولا تضع مفاتيح سرية أو Discord webhook في ملفات الواجهة العامة.

## النشر على GitHub Pages
ارفع محتويات المجلد إلى جذر المستودع (الملفات نفسها، وليس ملف ZIP فقط)، ثم افتح Settings → Pages وتأكد من النشر من `main` و`/(root)`. بعد اكتمال النشر افتح رابط الموقع، وللوحة الإدارة أضف `/admin.html` إلى نهاية الرابط.

هذا مشروع Roleplay خيالي مستقل وليس جهة حكومية أو موقعاً رسمياً لوكالة CIA.
